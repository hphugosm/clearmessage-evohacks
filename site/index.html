From confusion to action

A small flow for a difficult moment.

Built with older adults and unfamiliar users in mind. Human usability and spoken screen-reader testing remain future work.

  1. Bring the message

    Paste short text, or read an English screenshot in the full local app. The image stays in the browser; you review and confirm its text.

  2. Understand the finding

    Our trained classifier and transparent rules provide a result. Select a highlighted phrase to inspect an observed request, such as pressure to pay quickly.

  3. Choose your next step

    Use an official contact, pause payment, or ask someone you trust. ClearMessage prepares advice and a neutral help draft; you remain in control.

What we actually measured.

We trained a word-and-character TF-IDF + logistic regression classifier for three source labels: HAM, SPAM and SMISHING. We compared it with frozen multilingual MiniLM embeddings and selected TF-IDF using validation results.

5,873eligible dataset messages
0.864test macro-F1
74 / 88SMISHING annotations matched

These results measure agreement with dataset annotations on a previously evaluated 880-message test set. They are not independent blind validation or real-world fraud accuracy. The classifier missed 14 SMISHING annotations. English and Czech language-specific performance remains unverified.

A cautious prototype

Useful guidance.
Honest boundaries.

The full app sends confirmed message text to our FastAPI backend and processes it in memory. The application does not save message bodies or use them for training. It does not visit message links, use an external LLM, access an inbox or contact anyone.

Every current check is incomplete. ClearMessage cannot verify a sender or confirm that a message is safe. Rule highlights explain observed text, not the words behind the classifier’s prediction.

The public Pages demo contains a fictional recorded example and accepts no personal message input. GitHub may log visitor connection information. A public inference backend, its hosting logs and HTTPS configuration have not been verified.

The people behind the project

Team Trampolin.

We built ClearMessage for EVOHACKS 2026’s AI for Automation theme: automate the first inspection of a confusing message, then give the person a clear, practical next step.

Our work brings together a trained classifier, an accessible English interface, transparent rules, screenshot text recognition and privacy-conscious help sharing. Codex assisted implementation and testing.

React · TypeScript · Vite · FastAPI · Pydantic · scikit-learn · Tesseract.js. We reused the credited dataset, comparison encoder, OCR resources, font and third-party libraries. We did not train a large language model.
